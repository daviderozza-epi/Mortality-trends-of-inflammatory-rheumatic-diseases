# Mortality-trends-of-inflammatory-rheumatic-diseases
Mortality trends of gout, rheumatoid arthritis, spondyloarthritis, systemic lupus erythematosus and systemic sclerosis in 63 countries between 2000 and 2023: a WHO Mortality Database analysis.
This repo contains R scripts used to import WHO MDB, select countries based on the usability parameter, run multiply imputed bootstrap samples, and produce annual percent changes of standardised mortality rates.
